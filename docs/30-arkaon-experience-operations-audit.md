# ARKAON 화면·콘텐츠·운영 정합성 감사

ARKAON은 홈 화면부터 역할별 화면의 문구, 정보 배치, 핵심 행동, 모바일 가독성, 접근성과 이동경로를 지속 점검한다. Frontend·API·정책·실제 페이지 경로가 같은 후보 커밋에서 일치하는지도 검사한다.

공식자료로 확인된 타 플랫폼 기능은 사용자 문제, 해결방식과 효과만 비교한다. 문구·디자인·코드·브랜드를 복제하지 않고 나랑라이더 정책과 사용자 권리에 맞는 독자적인 합성 초안만 제안한다.

헤딩 오류, 핵심 행동 중복, 긴 문구, 대비 4.5:1 미달, 44px 미만 터치영역, 모바일 가로 넘침, 끊어진 링크, 화면–API–정책 경로 불일치는 즉시 개선제안으로 만든다. 즉시는 자동수정이 아니라 관리자 검토함에 지체 없이 제안한다는 뜻이다.

ARKAON의 최대 권한은 `IMPROVEMENT_PROPOSAL`이다. 변경 적용은 관리자 대화·부분수정 통제의 미리보기와 인석형 승인을 거쳐 검토 브랜치에서만 수행한다.
