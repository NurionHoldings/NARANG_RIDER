# 한국어 UX·접근성·권리문구 독립감사

## 판정

네 역할 포털(점주·라이더·고객·지사)의 정적 계약은 PASS다. 실제 보조기기·브라우저·운영 데이터가 필요한 검증은 **BLOCKED**이며 출시 승인으로 해석하지 않는다.

## 보강 범위

- 쉬운 한국어 상태명과 원화·한국 시간 표시 함수를 단일화했다.
- 고객 필수 안내문 `개봉 전 외관 이상이 있으면 먼저 신고해 주세요.`와 `외관 이상 신고` 버튼을 변경 감지 대상으로 고정했다.
- 거절·철회·환불·이의제기·개인정보 선택을 주요 업무와 같은 버튼 규격으로 제공한다.
- 선택 동의는 미선택 상태이며, 안내 미확인이나 동의 거부가 권리를 제한하지 않음을 명시한다.
- 위험 작업에는 결과 설명과 별도의 확인 체크를 요구한다. 시간 압박·자동 동의·카운트다운은 금지한다.
- 건너뛰기 링크, landmark, 제목 계층, 명시적 label, 오류 요약, `aria-live`, 로딩·비활성·오프라인 상태와 초점 이동을 보강했다.
- 320px reflow, 200% 텍스트 줄바꿈, 44px 터치 대상, 동작 축소, 색상에 의존하지 않는 상태 표현을 CSS 계약으로 고정했다.
- 핵심 색상 조합은 WCAG AA 일반 텍스트 4.5:1 기준을 계산한다.

## 한국어 상태 용어집

| 시스템 상태 | 화면 문구 | 의미 |
|---|---|---|
| `idle` | 대기 | 아직 요청하지 않음 |
| `submitting` | 처리 중 | 중복 요청을 막고 서버 응답을 기다림 |
| `offline` | 연결 끊김 | 자동 재전송하지 않음 |
| `conflict` | 변경 충돌 | 최신 내용을 확인한 뒤 다시 선택 |
| `expired` | 로그인 만료 | 다시 로그인 필요 |
| `error` | 처리 실패 | 입력을 유지하고 오류 요약으로 초점 이동 |
| `success` | 처리 완료 | 서버가 요청을 받음 |

## 검증 한계

정규식 기반 감사는 결정론적 회귀 방지 수단이다. 실제 스크린리더 발음·탐색 순서, 브라우저 확대, 고대비 모드, 모바일 가상키보드, 320px 실기기, 저시력·운동장애 사용성은 대체하지 못한다. 운영 파일럿 전 NVDA/JAWS/VoiceOver/TalkBack과 키보드 전수검증을 사람이 수행해야 한다.
