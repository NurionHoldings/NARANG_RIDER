# 지도 운영승격 통합 게이트·증거계보 검증 (#076)

상태: **BLOCKED**. 내부 합성 검증과 외부 증거를 한 판정표로 결합하지만 코드가 운영승격,
main 병합 또는 배포를 승인할 수는 없다.

## 내부 증거계보

문서 변경감시, Sandbox 계약시험, 기기 인증결과, 경로·ETA Shadow, 공급자 장애·예산통제
증거가 모두 동일한 후보 커밋에 연결되고 유효기간과 SHA-256 다이제스트를 가져야 한다.
누락·중복·만료·다른 커밋 증거는 실패 폐쇄한다.

## 외부 차단조건

EXT-02 공급자 Sandbox, EXT-03 전문검토, EXT-04 비운영 인프라, EXT-05 폐쇄시험,
EXT-07 최종 검토·운영자 승인을 모두 요구한다. `PENDING`이나 참조·만료·에테르니언
검토가 없는 상태는 `VERIFIED`로 취급하지 않는다.

## 승인 분리

에테르니언 최종 심사와 최인석 운영자 결정은 서로 다른 참조여야 한다. 모든 조건이 충족돼도
최대 자동판정은 `READY_FOR_OPERATOR_DECISION`이며, main 병합·배포·운영 활성화는 항상
`false`다. 현재 외부 차단조건이 PENDING이므로 실제 판정은 계속 `BLOCKED`다.
