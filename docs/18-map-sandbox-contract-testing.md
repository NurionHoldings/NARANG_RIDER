# 지도 Sandbox 계약시험 프레임워크 (#072)

상태: **BLOCKED**. 실제 공급자 Sandbox가 아니라 예약된 `.invalid` 호스트와 합성 응답만
사용한다. 네트워크·운영 키·실제 주소·좌표·주문·라이더 정보는 사용하지 않는다.

## 계약 검증

- 기능, HTTPS endpoint, path와 요청 필드를 명시적 허용목록으로 제한한다.
- 응답 상태와 필수 필드를 확인하고 예상하지 않은 개인정보 필드를 거부한다.
- Timeout, 쿼터 소진, 키 철회, 비정상 응답을 결정론적 합성 장애로 시험한다.
- 자격증명은 `vault-ref:synthetic:` 참조만 허용하며 원문 키는 Adapter 호출 전에 차단한다.
- 계약 위반이 있으면 Adapter를 호출하지 않고 실패 폐쇄한다.

## 승격 경계

계약시험 통과는 공급자 인증이나 운영승격이 아니다. 보고서는 항상 운영 활성화를
`false`로 유지하고 EXT-02를 `PENDING`으로 표시한다. 공식 공급자 자료와 실제 Sandbox
계약이 제공된 이후에도 에테르니언 독립심사, 기기시험, 운영자 승인이 별도로 필요하다.
