# #041 기능형 포털 사용자 여정

네 포털은 typed `ApiClient`와 서버 쿠키 세션·CSRF 계약을 사용한다. 운영 factory에는 demo session이나 고정 token 우회가 없다. 현재 실행 대상은 `local-synthetic` 백엔드뿐이며 실제 고객·라이더·점주의 개인정보를 입력하면 안 된다.

각 활성 폼은 메모리에만 멱등키를 유지한다. 이중 클릭은 진행 중 상태로 막고, 성공 시 키를 폐기한다. 오프라인 요청은 자동 재전송하지 않으며 사용자가 내용을 확인하고 `다시 시도`를 눌러야 한다. `409`는 최신 상태를 먼저 새로고침한다. `401/403/409/422/429`는 내부 오류나 payload를 노출하지 않는 한국어 안내로 변환한다.

폼에는 연결된 label, 도움말, `role=alert`, `aria-live`, 오류 발생 시 focus 이동이 있다. 사진은 브라우저 저장소나 cache에 저장하지 않으며 실시간 촬영 grant의 합성 참조만 전달한다.

CI 환경에서 새 브라우저 바이너리를 네트워크로 내려받지 않기 위해 Node DOM/source 계약 테스트를 사용한다. 따라서 실제 브라우저의 스크린리더·카메라 권한·키보드 탭 순서는 제한 지역 파일럿 전 별도 수동/브라우저 검증이 필요하다.
