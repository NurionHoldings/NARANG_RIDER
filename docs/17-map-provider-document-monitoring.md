# 지도 공급자 공식문서 변경감시·지식 만료 갱신 (#071)

상태: **BLOCKED**. 승인된 합성 Snapshot 비교만 구현하며 실제 공급자 문서 수집, API 호출,
운영 키 사용, 위치정보 처리, Registry 자동갱신과 운영 활성화는 하지 않는다.

## 감시 경계

- 공식 HTTPS 출처와 출처 권위 확인, 제목·조회시각·만료시각·SHA-256만 입력한다.
- 원문 문서는 보존하지 않고 Prompt Injection을 명령이 아닌 비신뢰 자료로 취급한다.
- 공급자 간 Snapshot 혼합과 과거 시점으로의 역행을 거부한다.
- scheme, host, path, query parameter, 키 정책, 보존·재위탁, 오토바이 지원 변화는
  파괴적 변경으로 분류한다.

## 실패 폐쇄 상태

- 동일하고 유효한 Snapshot만 `CURRENT`로 판정한다.
- 일반 본문 변경과 민감 필드 추가·삭제는 `HUMAN_REVIEW`로 보낸다.
- 만료된 근거는 `STALE`, 권위 미확인 또는 악성 지시 포함 자료는 `BLOCKED`로 보낸다.
- 모든 상태에서 운영 활성화는 `false`이며, 변경 시 계약시험과 에테르니언 독립심사를 요구한다.

## 갱신 절차

감시는 사람 검토용 제안과 결정론적 CI 아티팩트만 생성한다. Registry 쓰기, Adapter 수정,
모델학습, Canary, 운영 승격은 자동 수행하지 않는다. EXT-02 공식 자료·Sandbox 계약시험,
에테르니언 서명심사와 최인석 운영자 승인이 모두 갖춰져야 별도 변경으로 진행할 수 있다.
