# #048 에테르니언 독립 보안·정산 심층감사

감사 기준일: 2026-09-16  
대상: `0.1.0-rc.2` 롤업 HEAD `70ee0c1686ba66912e3041f14a7705915f8f1da7`

기존 ARKAON 구현 판정을 증거로 간주하지 않고 코드, 스키마, 테스트를 직접 검토했다.
실제 비밀정보·개인정보·결제·송금은 사용하지 않았다.

| ID | 심각도 | 발견 근거 | 조치 | 회귀 검증 |
|---|---|---|---|---|
| ETF-048-01 | 높음 | 지급 제공자 콜백이 `SUBMITTED` 전에도 지급지시를 `CONFIRMED`로 바꿀 수 있었다. | 2인 승인과 독립 실행 후 상태에서만 콜백 허용 | 사전 콜백 거부 테스트 |
| ETF-048-02 | 높음 | 영속 어댑터가 도메인 원장 생성자를 우회한 불균형·빈 원장을 저장할 수 있었다. DB에도 합계 제약이 없었다. | 어댑터 공통 signed double-entry 검증과 지연 DB 균형 트리거 추가 | 불균형·단일·bool 금액 적대 테스트 |

| ETF-048-04 | 중간 | 검증 전 콜백 event ID를 소비하여 위조 콜백이 정상 재시도를 오염시킬 수 있었다. | 서명·순서·금액·목적지 검증 통과 후에만 event ID 소비 | 위조 후 정상 처리 경계 테스트 |

## 잔여 제한

- 공식 제휴사 API·Sandbox, 공급자 서명 구현체, 운영 IAM/RLS 역할 구성은 외부 입력이 없어
  실증할 수 없다.
- 법률·개인정보 전문 검토와 제한 지역 현장 파일럿은 별도 승인 전까지 차단 상태다.
- 본 감사는 보안 인증이나 법률 승인에 해당하지 않는다.
- 출시 판정은 계속 `BLOCKED`이며 main 병합과 배포를 허가하지 않는다.
