# ARKAON 성찰학습과 교훈기억

ARKAON은 타 플랫폼을 모방하지 않고 자신을 비추는 비교 대상으로 삼는다. 외부 기능이 해결한 사용자 문제를 관찰하고 나랑라이더의 현재 강점, 부족함, 근본원인, 사용자 영향과 정책충돌을 함께 기록한다.

`관찰 → 자기격차 → 개선가설 → 합성 Shadow → 에테르니언 심사 → 운영자 결정 → 교훈기억` 순서는 생략할 수 없다. 개선 전 Baseline과 후보 결과를 같은 측정기준으로 비교한다.

채택된 결과뿐 아니라 기각·보류·실패·회귀도 이유와 함께 불변 교훈으로 남긴다. 이를 통해 같은 아이디어와 실패를 반복하지 않는다. 공통으로 재사용하는 것은 공개근거, 추상정책, 합성시험 패턴과 검토된 교훈뿐이며 회원·주문·위치·결제·정산·본인확인 자료는 기억에 넣지 않는다.

성찰학습은 모델 가중치 변경이 아니다. ARKAON은 자신의 Prompt·가중치·평가기준을 변경하거나 실패를 삭제하고 스스로 승인할 수 없다. 실제 개선은 관리자 부분수정 통제와 인석형 승인을 거친다.
