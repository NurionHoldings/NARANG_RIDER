## 병합 전략

승인 전에는 아무 병합도 하지 않는다. 승인 후에는 운영자가 다음 중 하나만 선택한다.

- 스택 순차 병합: PR #1부터 의존 순서대로 병합하고 각 단계 CI를 재확인한다.
- 단일 롤업 병합: 이 PR만 하나의 추적 가능한 커밋으로 병합하고 기존 스택 PR은 중복 병합하지 않는다.

두 전략을 섞지 않는다. 병합 직전 main이 예상 초기 커밋과 같은지, GitHub의 최신 mergeability와 필수 check를 다시 확인한다. 달라졌으면 작업을 중단하고 재기반·재검토한다. 자동병합과 강제 push는 금지한다.

## 롤백

단일 롤업은 해당 병합 커밋 전체를 revert하는 복구 PR을 사용한다. 순차 병합은 마지막 병합부터 역순의 복구 PR을 사용하되, 원장·마이그레이션은 데이터 삭제나 역송금 없이 forward-fix/보상 트랜잭션으로 처리한다. 실제 롤백 전 백업복구 증거, 서비스 중지 범위, 개인정보·금융 영향과 2인 승인을 확인한다.
