# ARKAON 유사업종 기능 조사·협의 체계

ARKAON은 배달·라이더·모빌리티·오토바이 금융·중고거래·보험 비교·전자계약 분야의 새 기능을 조사할 수 있다. 공식 HTTPS 출처와 등록된 공식 host만 수집하며 URL·제목·게시일·조회일·만료·본문 digest를 기록한다.

인터넷 자료는 모두 비신뢰 격리 입력이다. `격리 → 근거검증 → 에테르니언 검토 → 개선제안 → 운영자 결정` 순서를 거치며 자동 학습, 운영 Prompt·가중치 변경, 코드 자동적용, 병합 또는 배포는 금지한다.

PC 시작 감지는 클라우드가 직접 수행할 수 없으므로 Windows 작업 스케줄러용 등록 스크립트를 제공한다. 이는 인석형 PC에서 명시적으로 실행해야 활성화된다. 컴퓨터명·사용자명·하드웨어 식별자를 수집하지 않고 로컬 조사 트리거만 발생시킨다.

별도로 ChatGPT 정기 자동화가 매일 공식자료를 조사해 에테르니언 검토 후보와 개선안을 보고한다. 의미 있는 새 근거가 없으면 변경을 만들지 않는다.
