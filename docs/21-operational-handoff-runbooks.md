# 나랑라이더 운영 인수인계 런북 v0.1

이 문서는 합성 훈련용 운영 기준이며 법률·보안 인증 또는 실제 운영 승인이 아니다. 명령 예시는
운영 시스템을 자동 변경하지 않는다. 운영 비밀값·개인정보·정밀위치를 문서와 채팅에 입력하지 않는다.

## 1. 당직 역할과 심각도

- `SEV1`: 안전, 개인정보, 인증 전체 장애, DB·원장·지급 무결성 위험. HQ 사고지휘관 호출.
- `SEV2`: 한 공급자·권역·기능의 중대 저하. 권역 담당자가 격리하고 HQ에 알린다.
- `SEV3`: 제한적 오류이며 안전·돈·개인정보 영향 없음. 지역지사가 기록하고 정상 절차로 수정한다.
- HQ는 전국 조정, 권역은 소속 지사 조정, 지역은 자기 지사만 조치한다.
- ARKAON은 요약·추천·설명만 한다. 재시작, 배차 배제, 보수 변경, 지급, 제재를 승인하지 않는다.

모든 사건 기록은 사건번호, 합성/운영 구분, UTC·KST 시각, 영향 범위, 비식별 증거 참조,
승인자, 복구 검증, 사후조치로 구성한다.

## 2. 공통 사건지휘 런북

- 탐지: readiness 저하, 오류율·queue age·DLQ·분쟁 증가, 안전 또는 개인정보 신고.
- 안전 격리: 영향 지사·공급자만 최소 범위로 격리하고 비영향 기능은 유지한다.
- 금지: 원장 수정·삭제, 라이더 보수 자동환수, 실데이터 복사, ARKAON 단독 결정.
- 승인: SEV1은 사고지휘관과 분야별 독립 승인자, 금융복구는 재무와 운영 승인자.
- 복구: 원인 제거, 합성 재현시험, 지사 범위 확인, 독립 사람 승인 후 단계 재개.
- 사후검토: 타임라인·영향·근본원인·권리영향·재발방지·담당기한.

## 3. 인증·JWKS 장애

- 탐지: `JWKS_REFRESH_FAILURE`, 인증 실패율, 알 수 없는 signing key 증가.
- 격리: 특권 쓰기를 fail-closed로 중지하고 승인된 짧은 캐시만 사용한다.
- 금지: 서명검증 우회, 임의 대칭키 전환, 토큰 claims를 권한 원장으로 사용.
- 승인: 보안검토자 + 운영승인자. 증거: `src/narang_rider/authentication.py`.
- 복구: 발급자·audience·알고리즘·키교체·replay 시험 통과.

## 4. DB 장애·복구

- 탐지: readiness down, serialization/timeout 급증, RLS 오류.
- 격리: 신규 금융쓰기를 중단하고 Outbox·원장 스냅샷을 보존한다.
- 금지: 검증 전 primary 전환, RLS 비활성화, 원장 행 직접 수정.
- 승인: HQ 사고지휘관 + 운영승인자. 증거: `migrations/0001_postgres_persistence.sql`.
- 복구: 합성 restore, RPO/RTO 증거, RLS·원장균형·멱등성 재검증.

## 5. Outbox·제휴사 장애

- 탐지: DLQ 증가, circuit open, callback 순서 불일치.
- 격리: 해당 제휴사만 정지하고 stream 순서를 유지하며 DLQ를 사람 심사로 보낸다.
- 금지: 순서 건너뛰기, 무제한 재시도, DLQ 기반 자동 금융조정.
- 승인: 권역담당자 + 운영승인자. 증거: `src/narang_rider/outbox_worker.py`.
- 복구: 같은 idempotency key의 합성 재전송과 중복 0건 확인.

## 6. 정산 불일치·지급 보류

- 탐지: 금액·목적지·sequence·서명 불일치.
- 격리: 분쟁 항목만 보류하고 비분쟁 금액은 지급 가능 상태로 유지한다.
- 금지: 라이더 보수 자동환수, 전체 정산 일괄동결, 콜백만으로 책임확정.
- 승인: 서로 다른 재무검토자 + 운영승인자. 증거: `migrations/0002_settlement_operations.sql`.
- 복구: 원장균형, statement hash, 목적지 Vault 참조, 제공자 영수증 사람 대사.

## 7. 개인정보 침해·DSAR

- 탐지: 비인가 접근, 내보내기 범위 초과, 권리요청 기한 위험.
- 격리: 노출 참조를 폐기하고 최소 감사기록만 보존한다.
- 금지: 다른 정보주체 자료 포함, 원장 삭제, AI의 침해 여부 확정.
- 승인: 개인정보책임자 + 운영승인자. 증거: `docs/16-privacy-rights-retention.md`.
- 복구: 열람·정정·삭제·제한·이의제기 경로와 법적 보존 범위를 사람 검증.

## 8. 배송증거·미디어 실패

- 탐지: 마스킹·EXIF 제거·악성파일 검사 실패, nonce 재사용.
- 격리: 미디어 저장을 중지하고 촬영불가 사유 경로를 제공한다.
- 금지: 마스킹 전 원본 저장, 갤러리 우회, 사진만으로 책임·환불 결정.
- 승인: 개인정보책임자 + 해당 지역담당자. 증거: `src/narang_rider/evidence.py`.
- 복구: 2~3 프레임, 1회 nonce, 원본 미보존, 고객·라이더 권리 유지 확인.

## 9. 지도·알림 장애

- 탐지: 지도 timeout, ETA drift, 알림 제공자 failure.
- 격리: 보수에 불리하지 않은 공개견적과 최소 대체 알림을 쓴다.
- 금지: 대체 알림에 주소·전화·정밀위치·라이더 ID·주문내용 포함.
- 승인: 권역담당자 + 지역담당자. 증거: `src/narang_rider/geospatial.py`.
- 복구: 잠금화면 최소정보, 방해금지, 위치추적 종료, 권리 비제한 확인.

## 10. 안전·보험 사건

- 탐지: 라이더 안전중지, 사고신고, 보험 조회 실패.
- 격리: 배차를 멈추고 무불이익 상태로 전환하며 미분쟁 수익을 보호한다.
- 금지: 의료정보 로그, 사진만으로 과실·보험 거절, 거절 보복배차.
- 승인: 안전담당자 + 운영승인자. 증거: `migrations/0004_rider_incident_support.sql`.
- 복구: 사람 상담, 보장 스냅샷, 이의제기·정정 경로 확인.

## 11. 용량초과

- 탐지: queue age, timeout, 429, 메모리 예산 초과.
- 격리: 신원과 무관한 동일 기준으로 load shed하고 `Retry-After`를 제공한다.
- 금지: 라이더 수락률·거절이력·점주 등급별 차별 제한, 무제한 queue.
- 승인: HQ 사고지휘관 + 권역담당자. 증거: `docs/10-performance-resource-audit.md`.
- 복구: bounded 합성시험, 안전·정산 우선순위, 공정성 지표 불변 확인.

## 12. 릴리스 롤백

- 탐지: 핵심 불변식, error budget, migration 호환성 실패.
- 격리: rollout을 정지하고 코드만 이전 검증본으로 되돌릴 준비를 한다.
- 금지: 자동 main 병합·배포, 파괴적 DB downgrade, 승인 없는 재개.
- 승인: HQ 사고지휘관 + 운영승인자. 증거: `docs/18-release-candidate-handoff.md`.
- 복구: schema 호환, 합성 E2E, 보안·원장·RLS 시험, 단계적 재개.
