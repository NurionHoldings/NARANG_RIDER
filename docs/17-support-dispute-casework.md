# #043 공통 지원·분쟁 사건처리

고객·점주·라이더·제휴사는 배송, 파손, 환불, 결제, 정산, 배차, 안전, 개인정보, 보험, 제휴 사건을 동일한 지사 범위 사건처리 흐름으로 접수한다. 본인 또는 보호 저장소의 대리권 참조를 확인하고, 원문 연락처·메시지·증거는 애플리케이션에 저장하지 않는다. 당사자 화면에는 다른 당사자의 연락처, 내부 메모와 자신이 정보주체가 아닌 증거를 표시하지 않는다.

사건은 open → triage → assigned → waiting_party/review → resolved → appealed/closed 순서다. 해결·종결에는 사람의 사유 참조와 권리안내가 필요하다. 이의신청 검토자는 최초 담당자·해결자·당사자와 달라야 한다. 사건 배정은 전문분야와 현재 활성 사건 수만 사용하며 상담원 속도·평가·성과압박에 사용하지 않는다.

사진 전후 비교, 반복·연계 신호와 아르카온의 요약·분류·누락자료 제안은 사람 검토 우선순위를 돕는 정보다. 이 정보만으로 책임, 환불거절, 계정제재, 보수환수, 보험 판단 또는 사건 종결을 결정하지 않는다. 라이더 귀책이 사람 절차로 최종 확정되기 전에는 보수를 환수하지 않는다.

임시 크레딧·환불·결제조정은 직접 실행하지 않고 기존 금융 2인 통제에 전달할 멱등 지시를 Outbox에 기록한다. 본 단계는 실제 환불·결제·개인정보 접근을 수행하지 않으며 합성 참조만으로 검증한다.
