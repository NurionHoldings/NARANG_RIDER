# ARKAON 공통 능력치 Profile·Benchmark·승격 통제

## 범위

이 기능은 ARKAON의 조사·추론·개발·검증 능력을 10개 독립 영역으로 평가한다. 나랑라이더를 최초 적용 대상으로 삼지만, AI배비·도시락.store·MJN·부업장터·wither·AI법친·AI-ABA에서 정책·스키마·평가방법·합성시험만 재사용할 수 있다. 회원·주문·위치·정산 등 실제 데이터는 플랫폼 사이에 공유하지 않는다.

## 평가 계약

버전형 Profile은 정확도, 재현율, 근거 없는 주장률, 위험 제안률, 회귀 탐지율의 임계값을 고정한다. 모든 10개 영역의 합성 사례가 있어야 하며 사례 원문은 SHA-256으로 고정한다. 인터넷 문서에 포함된 지시는 비신뢰 입력이며, 운영 접근·자기 변경·기준 완화·실패 시험 삭제 제안은 허용 오차 0으로 실패한다.

CI 산출물 `build/arkaon-capability-benchmark.json`은 사례 manifest와 결과 digest를 포함한다. 이 결과는 합성 평가 증거일 뿐 모델 품질 인증, 실제 모델학습, 운영 활성화 또는 사용자 대상 결정 권한을 부여하지 않는다.

## 승격 상태기계

`Baseline → Proposal → Synthetic Shadow → 에테르니언 심사 → 운영자 승인 → 제한 승격 → Rollback`

- 에테르니언 심사와 운영자 승인은 동일 참조를 사용할 수 없다.
- 제한 승격 범위는 `synthetic:` 접두사의 합성환경만 허용한다.
- 코드가 운영 승인, 병합, 배포 또는 실제 데이터 접근을 대신하지 않는다.
- 운영자 승인 전 후보는 운영 Prompt·가중치·기준을 변경할 수 없다.
