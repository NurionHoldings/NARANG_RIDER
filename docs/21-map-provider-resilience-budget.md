# 지도 공급자 장애전환·비용·쿼터 예산통제 (#075)

상태: **BLOCKED**. 합성 공급자 정책만 평가하며 실제 지도 API 호출, 운영 키, 청구 또는
외부 지도 앱 자동 전환은 수행하지 않는다.

## 장애·쿼터 통제

- 공급자별 회로차단기와 실패 횟수를 격리한다.
- 일일 쿼터, 보호 예비량과 월간 비용예산을 초과하기 전에 실패 폐쇄한다.
- 동일 요청은 SHA-256 멱등 다이제스트로 비용·쿼터를 한 번만 예약한다.
- 오래되거나 미인증인 공급자, 기능이 없는 공급자와 오토바이 적합성 미검증 공급자를 제외한다.

## 장애전환 경계

선호 공급자를 사용할 수 없어도 외부 지도 앱을 자동으로 바꾸지 않는다. 동등한 인증 기능을
가진 후보만 제시하며 라이더의 명시적 선택을 요구한다. 후보가 없으면 `BLOCKED`다.

## 공정성·승격

장애전환 결과로 보수를 낮추거나 라이더를 제재할 수 없다. Planner는 실제 공급자 호출 권한이
없으며 EXT-02 자료·Sandbox·비용계약, 에테르니언 심사와 운영자 승인 전까지 운영 활성화는
항상 `false`다.
