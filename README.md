# 나랑라이더 (NARANG RIDER)

> 나랑 달리고, 나란히 성장하다.

라이더·자영업자·지역이 함께 성장하는 상생형 배달대행 플랫폼입니다.

## 프로젝트 상태

- 브랜드: `WORKING_BRAND`
- 단계: `FOUNDATION`
- 공통 식별자: `NARANG_RIDER`
- 기본 브랜치: `main`
- 개발 방식: 기능 브랜치 → Pull Request → CI → 검토 후 병합

## 핵심 가치

1. 라이더의 시간당·건당 순수익 보호
2. 거리·대기·기상·난이도·복귀비용을 반영한 공개 단가
3. 자영업자의 주문당 순이익과 비용 상한 보호
4. 빠르고 검증 가능한 정산
5. 산재·보험·사고 대응과 안전 지원
6. 지역 수익 공유와 공동물류
7. 데이터 권리, 설명 요구권 및 배차 이의제기
8. 독점·락인·보복 배차 방지

## AI 운영 원칙

ARKAON은 수요 예측, 공정 배차, 수익 최적화와 운영 지원에 사용합니다.  
노동 통제, 부당한 감시, 차별, 불투명한 등급화 또는 보복 배차에는 사용하지 않습니다.

## 역할

- **ARKAON**: 조사, 가설 수립, 경제성 및 악용 가능성 테스트
- **에테르니언**: 근거, 법적 경계, 보안, 정산 공정성과 실현 가능성 독립 감독
- **운영자**: 핵심 정책과 실제 자산 승격의 최종 승인

## 예정 산출물

- 핵심 철학 및 이해관계자 가치
- 시장·업무 흐름과 착취 구조 분석
- 공정 배차 및 공개 단가 모델
- 정산·안전·보험·개인정보 설계
- 도메인 모델과 API 계약
- 라이더·가맹점·지역허브 MVP
- 위협 모델과 검증 가능한 테스트

## 구현 현황

`#001 Core Money & Decision Contract` 기능 브랜치에서 다음 기반을 구현합니다.

- 거리·대기·복귀·묶음·안전 가산을 분리한 공개 단가 견적
- 수락 전 라이더 건당·시간당 예상 순수익
- 거절이력·보호특성·AI 점수를 차단하는 설명 가능한 FIFO 배차 영수증
- 점주 부담 상한과 고객·점주·라이더·안전·지역기금을 연결하는 불변 정산 원장
- one-time 인앱 촬영과 사람심사를 강제하는 개인정보 최소형 배송증거 영수증

근거와 기존 capability 추적표는
[시장 조사 및 baseline capability matrix](docs/01-research-and-capability-matrix.md), 구현 경계는
[MVP foundation contract](docs/02-mvp-foundation.md)를 참조합니다.
