# 실제 기기 인증 결과 수신·위변조 방지 (#073)

상태: **BLOCKED**. 이 기능은 실제 기기를 제어하거나 지도 앱을 실행하지 않고, 승인된 외부
기기시험 절차가 나중에 생성할 수 있는 최소화된 결과 봉투를 검증하는 수신 경계만 제공한다.

## 무결성 통제

- 버전형 스키마, 등록된 검증자 키, SHA-256 payload digest와 서명을 확인한다.
- 증거 유효기간은 최대 1시간이며 미래 발급·만료·nonce 재전송·증거 ID 중복을 거부한다.
- 설치 실행, 미설치, 업데이트 필요, OS 제한, 오프라인, 복귀상태 일회성, 접근성 시험을
  빠짐없이 요구한다.
- 하나라도 실패하면 `BLOCKED`, 모두 통과해도 `HUMAN_REVIEW`로만 접수한다.

## 개인정보 최소화

기기 일련번호·광고 ID·IMEI·전화번호·라이더·주문·주소·좌표·API 키를 받지 않는다.
기기군은 단방향 hash만 허용하며 접수 영수증에는 기기 hash도 포함하지 않는다.

## 승격 경계

접수 결과는 공급자 `VERIFIED`, 실제 Scheme 인증 또는 운영활성화를 만들 수 없다.
EXT-05 폐쇄 Sandbox·실기기·보조기기 시험, 에테르니언 독립심사와 최인석 운영자 승인이
별도 증거로 완료될 때까지 출시 상태는 `BLOCKED`다.
