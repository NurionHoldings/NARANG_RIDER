# 나랑라이더 전문가 독립검토 패키지

기준 버전: 0.1.0-rc.5 + PR #060  
범위: 전국 Sandbox 출시후보  
성격: 사실·질문·증거 묶음이며 법률·세무·노무·보험·금융 결론이 아니다. 대한민국 관할과 검토일 현재의 법령·감독지침을 전문가가 다시 확인해야 한다.

## 1. 시스템 사실 요약

나랑라이더는 점주 주문접수, 공정단가·FIFO 배차, 라이더 수행, 개인정보 보호형 배송증거, 고객 신고, 복식원장 정산, 지급지시, 전국 지사 관제를 제공한다. ARKAON은 수요·조리·주행시간 예측과 운영 자문만 하며 배차 배제, 보수 삭감, 계정정지, 보험료 차등, 노동통제, 차별 및 보복배차를 결정하지 못한다.

데이터 흐름은 매장/POS/플랫폼 → 주문 최소정보·Vault 참조 → 지사 라우팅 → 라이더 제안·수행 → 마스킹 배송증거 → 고객 알림/신고 → 사람 심사 → 원장·정산·지급지시 → 최소 운영지표 순이다. 주소·전화번호·정밀좌표·의료정보·지급수단은 도메인 저장 대신 Vault 참조를 사용한다. 외부 지도·알림·보험·결제·악성파일 검사에는 목적상 필요한 최소필드만 전달하도록 설계했으나 실제 공급자 계약은 미확정이다.

## 2. 역할·처리목록

| 주체/처리 | 현재 설계상 역할 | 주요 자료 | 보존·통제 |
|---|---|---|---|
| 본사 | 공통 정책·원장·관제 | 주문ID, 정산, 감사기록 | 금융·감사 불변성, 지사 범위 |
| 권역/지역지사 | 주문 운영·사고대응 | 관할 주문·합성 지표 | RLS, 최소집단 지표 |
| 점주 | 주문·포장·호출 | 메뉴/금액, 봉인·포장 | 호출 중복 차단 |
| 라이더 | 독립 수행자 전제, 법적 분류 미확정 | 가용성, 배차·배송 상태 | 거절 무불이익, 안전중지 |
| 고객 | 주문 수취·신고 | 마스킹 증거, 신고사진 | 인앱 촬영, 사람 심사 |
| 외부 공급자 | 처리자/독립처리자 여부 미결정 | 지도·알림·보험·결제 최소필드 | 계약·국외이전·재위탁 미확정 |

개인정보 범주는 계정/연락, 주문, 위치, 배송증거, 사고·보험, 지급, 지원·분쟁이다. 열람·정정·삭제·제한·내보내기·이의제기 흐름이 있으며 금융원장과 감사기록은 삭제 대신 신원연결 분리를 전제로 한다. 정확한 보존기간, 법적 보존근거, 국외이전과 재위탁자는 전문가·공급자 확인 전 BLOCKED다.

## 3. 주요 권리·운영 경계

- 라이더: 공개 보수·순수익·사유, 거절/만료 무불이익, 안전중지, 사고 이후 미분쟁 수익 보호, 귀책 확정 전 환수 금지.
- 점주·고객: 주문별 경제성, 이중포장 책임 분리, 개봉 전 신고 안내, 사진만으로 자동환불 기각·제재 금지.
- 정산: 허용 공제만 적용, 비분쟁액 지급, 지급 요청/승인/실행 직무분리, 콜백·금액 대사.
- 위치·미디어: 목적·시간 제한, 배송 후 추적 종료, 마스킹 전 원본 미보존, 학습·마케팅·라이더 평가 재사용 금지.
- 사고·분쟁: AI 자동책임 확정 금지, 사람 심사·독립 이의심사, SEV 대응과 금융 복구 2인 승인.
- 전국지사: 본사 공통 하한을 지사가 약화할 수 없고 지사 간 이전은 양측 승인.
- 외부 연동: Sandbox 자료·공식 계약·전문가 판정 전 인증 및 출시 금지.

## 5. 수신·판정 규칙

각 전문가는 서로 다른 등록 신원으로 검토하고, 범위·시스템 버전·유효기간·조건·이해상충을 포함한 서명된 불투명 승인 참조만 제출한다. 원문 의견서에는 개인정보나 비밀을 넣지 않고 승인된 문서보관소 참조를 사용한다. 조건부·거절·철회·만료·범위불일치·동일인의 다분야 검토는 승인으로 계산하지 않는다.

필수 분야는 법률·개인정보, 노무·보험, 회계·세무, 전자금융, 위치다. 모두 독립 ACCEPTED이고 미해결 조건이 없으며 운영자가 동일 범위·버전을 서명 수락해야만 내부 legal_approval 표지가 참이 될 수 있다. 이 표지는 정부·법원·감독기관 승인이나 출시 승인을 뜻하지 않으며 출시 상태는 계속 BLOCKED다.

## 6. 출처 최신성

기존 조사 문서의 공식 출처 URL·조회일을 검토 입력으로 사용하되 절대적 법률 결론으로 재사용하지 않는다. 전문가는 대한민국 관할, 검토 당일 시행 중인 원문, 유권해석·감독지침과 실제 계약을 확인하고 출처 URL·접근일·버전·문서해시를 남긴다. 법령·정책·시스템 버전 또는 실제 운영 방식이 바뀌면 재검토한다.
