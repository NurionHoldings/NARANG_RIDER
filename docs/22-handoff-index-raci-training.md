# 운영 인수인계 색인·RACI·훈련 확인서

## 인수인계 체크리스트

- [ ] 담당자가 `docs/21-operational-handoff-runbooks.md`를 읽고 역할 범위를 설명한다.
- [ ] 연락망은 Vault 또는 승인된 운영시스템에만 저장한다.
- [ ] SEV1 합성훈련에서 탐지→격리→독립승인→복구→사후검토를 수행한다.
- [ ] 금융 2인 승인, 지사범위, 라이더 무환수, ARKAON 자문 전용을 확인한다.
- [ ] 비밀값 없이 백업·복구, JWKS 교체, 제휴사 격리, 롤백을 연습한다.
- [ ] 외부 차단조건과 운영자 미결사항을 인계받는다.

## RACI

| 업무 | HQ 사고지휘 | 권역 | 지역 | 보안 | 재무 | 개인정보 | 안전 | 운영승인자 |
|---|---|---|---|---|---|---|---|---|
| SEV1 지휘 | A/R | C | I | C | C | C | C | A |
| 지사 격리 | A | R | R | C | I | I | C | C |
| 인증 복구 | C | I | I | R | I | I | I | A |
| 지급 재개 | I | I | I | I | R | I | I | A |
| 침해·DSAR | I | I | I | C | I | R | I | A |
| 사고·보험 | I | C | R | I | I | I | R | A |
| 롤백 승인 | R | C | I | C | C | C | C | A |

R=수행, A=최종 책임·승인, C=협의, I=통보. 동일인이 금융 요청·승인·실행을 겸하지 않는다.

## 용어

- RLS: PostgreSQL 행 단위 지사 격리
- Outbox: 업무 트랜잭션과 함께 기록되는 전달 대기 사건
- DLQ: 반복 실패 후 자동 처리를 멈추고 사람 심사로 보내는 대기열
- JWKS: 토큰 서명 공개키 집합
- DSAR: 정보주체 열람·정정·삭제·제한 등 권리요청
- RPO/RTO: 허용 데이터 손실 시점·복구 목표시간
- fail-closed: 검증할 수 없으면 권한·금융 처리를 허용하지 않는 방식

## 운영자 교육 확인문항

자동 채점용이며 이용자 지식평가가 아니다. 정답 기준:

1. 지급금액 불일치 시 전체 지급을 막는가? → 아니오, 분쟁 항목만 보류한다.
2. ARKAON이 장애복구 재시작을 승인할 수 있는가? → 아니오.
3. 배송사진 실패를 라이더 보수환수로 처리하는가? → 아니오.
4. 지역담당자가 다른 지사를 격리할 수 있는가? → 아니오.
5. 대체 알림에 주소나 정밀위치를 넣는가? → 아니오.
6. 금융복구에 한 사람 승인으로 충분한가? → 아니오.
7. DB 복구 시 원장을 직접 수정해 맞추는가? → 아니오.
8. 복구 전 필요한 것은? → 원인 제거, 합성증거, 독립 사람 승인.

교육 완료는 법률준수·보안인증·운영승인을 의미하지 않는다.
