# #037 합성 전국 부하·경제성·악용 시뮬레이션

## 용도와 해석 제한

이 하니스는 실제 개인정보·위치·거래·기상자료 없이 결정론적 합성 주문을 만들어 코드
불변식과 용량 임계치를 점검한다. 결과는 운영실적, 임금·수익 보장, SLA, 전국 처리능력,
시장예측, 투자근거가 아니다. 실제 사업 판단에는 승인된 현장 파일럿과 독립된 통계 검증이
필요하다. 보고서에는 `synthetic_only=true`와 해당 면책문구를 항상 포함한다.

## 재현 가능한 시나리오

- 고정 seed로 전국 지사·점주·라이더·주문 식별자를 모두 `syn-*` 형태로 생성한다.
- 수요 분류는 `normal`, `rain_like`, `heat_like`, `flash`이며 실제 날씨가 아니다.
- 주문접수→제안→수락→Outbox→정산을 가상 동시 처리 lane에서 수행한다.
- CI 기본 프로필은 8개 지사·800건·동시성 32로 실행시간을 제한한다.
- 180개 지사·25만 건 프로필은 수동 실행 전용이며 CI에서 자동 실행하지 않는다.

## 측정과 불변식

기계 판독 JSON은 p50/p95/p99 지연, 처리량, 최대 대기열 나이, 중복·실패율, 공정배차
대기분포, 비용 차감 라이더 순시급, 점주 공헌이익, 플랫폼 단위경제, 지역기금을 포함한다.
안전·법적 보수 하한, 원장 균형, 음수 지급 금지, 지사간 쓰기 차단, 거절 불이익 금지,
AI 금지결정 차단은 별도의 통과/실패 불변식으로 기록한다.

합성 경제성 수치가 낮거나 음수인 경우도 숨기지 않는다. 다만 그 값은 현장 가격·원가의
증거가 아니라 가격정책과 파일럿 설계를 다시 검토하게 하는 가설 신호다.

## 악용·장애 시나리오

- 주문·콜백 재전송은 멱등 재생으로 처리한다.
- 다중계정 연계신호와 GPS 이상은 사람 조사 우선순위로만 사용한다.
- 견적변조, 결탁 묶음, 취소·환불 조작은 금융변경 없이 차단한다.
- 알림 폭주와 파트너 장애는 제한 재시도·회로차단·Dead Letter 심사로 격리한다.
- DB deadlock은 전체 트랜잭션을 재시도해 단 한 번만 확정한다.
- 어떤 합성 신호도 자동 제재·보수환수·배차배제·보험차등을 허용하지 않는다.

## 실행

```bash
python scripts/run_synthetic_simulation.py --profile smoke
```

대규모 프로필은 의도적인 수동 검증에서만 `--profile manual-national`로 실행한다. 외부
네트워크·지도·운영 키·개인정보는 필요하지 않다.
