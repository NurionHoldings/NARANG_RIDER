# NARANG RIDER 0.1.0-rc.1 출시후보 운영 인계

## 판정

이 버전은 코드·계약·합성시험을 묶은 **출시후보**이며 출시 승인이 아니다. 공식 제휴 API와 Sandbox 자격증명, 지도·알림·보험 공급자 Sandbox, 법률·개인정보 전문승인, 운영자 승인, main 병합, 운영 인프라·비밀정보, 제한 지역 현장 파일럿이 없어 판정은 `BLOCKED`다. 어떠한 법률 준수·보안 인증·제휴 인증도 주장하지 않는다.

## 동결과 예외

RC 커밋 이후 코드는 동결한다. 문서화된 알려진 한계와 기계 생성 보고서 이외 변경은 사유, 위험 참조, 롤백 계획, 만료일, 에테르니언과 운영자 최인석의 독립 승인이 모두 있는 예외만 허용한다. 예외는 main 병합이나 배포 승인을 대신하지 않는다.

## 최종 smoke와 운영 인계

운영 담당자는 설정 fail-closed, DB 마이그레이션·RLS, OIDC/JWKS 교체, 주문→배차→배송→증거→정산, 원장 균형, Outbox/DLQ, 지사 중지·2인 재개, 백업복구, 개인정보 권리, 분쟁 이의신청, 롤백 연습을 실제 승인된 Sandbox와 합성 계정으로 다시 확인한다. 실제 개인정보·결제·송금은 파일럿 승인 전 사용하지 않는다.

## 알려진 한계

- `ai배비`·`도시락.store` 프로필은 공식 API 계약이 아닌 잠정 계약이다.
- 지도·알림·보험 연동은 합성 계약이며 공급자 인증이 아니다.
- DOM 접근성 계약은 실제 브라우저·보조기기 검사를 대체하지 않는다.
- 합성 부하·경제성 시험은 전국 현장 수요와 네트워크 상태를 증명하지 않는다.
- 공식 법률·개인정보·보험·노무 검토와 제한 지역 현장 파일럿이 남아 있다.

`scripts/verify_release_stack.py`는 GitHub API를 호출하지 않는다. CI가 `fetch-depth: 0`으로 가져온 선언된 브랜치들의 git ancestry만 검증한다. PR의 실시간 open/merged 상태는 증명할 수 없으므로 병합 전 권한 있는 GitHub 검토자가 `release/stack-inventory.json`을 다시 대조해야 한다.
